## Overview

This repository contains the source code for a personal portfolio website designed to showcase personal information, educational background, technical skills, hobbies, and contact details.

The website features a modern dark interface, responsive layout, and bilingual content (English and Indonesian).

It serves as a digital platform to introduce the portfolio owner and present their interests and abilities in technology and web development.

**Live Demo:** [https://luckycde.github.io](https://luckycde.github.io/)

## Website Sections

| Section | Description |
|---|---|
| Home | Displays a personal introduction and profile image. |
| About Me | Presents personal background, education, and interests. |
| Skills | Showcases technical skills and proficiency levels. |
| Hobbies | Displays personal interests and activities. |
| Contact | Provides contact information and a message form. |

## Features

- **Bilingual Website** — Available in English and Indonesian.
- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Dark Theme** — Modern dark interface with custom styling.
- **Skill Progress Bars** — Visual representation of technical abilities.
- **Contact Form** — Allows visitors to send messages through FormSubmit.
- **Social Media Links** — Provides access to social profiles.

## Technologies Used

| Technology | Description |
|---|---|
| HTML | Structures website content. |
| CSS | Handles styling, layouts, and visual effects. |
| Bootstrap | Provides responsive components and grid system. |
| Bootstrap Icons | Provides interface icons. |
| Devicon | Displays programming and technology icons. |
| FormSubmit | Handles contact form submissions. |
| GitHub Pages | Hosts and publishes the website. |

## Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/luckycde/luckycde.github.io.git
```

### 2. Open Project Folder

```bash
cd luckycde.github.io
```

### 3. Run Website

Open `index.html` in your browser.

To access the Indonesian version, open `id.html`.

No additional installation or build process is required.
